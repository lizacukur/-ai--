# Первая настройка: ключи API и где это вообще работает

Читай этот файл, если человек только что установил скилл и ключей Avito API
ещё нет, либо явно спрашивает «как подключить», «как получить ключи»,
«почему не видно моих объявлений».

## Где это работает, а где нет

**Надёжно работает в Claude Code** (CLI, десктоп-приложение или облачная
версия на claude.ai/code) — там у сессии есть обычный исходящий доступ
в интернет, которым может пользоваться код скилла.

**На claude.ai в браузере (обычный чат со скиллами) — доступ к интернету
не гарантирован.** Там скилл выполняется в песочнице, и её сетевой доступ
зависит от настроек аккаунта/организации: он может быть полным, ограниченным
только менеджерами пакетов (pip/npm) или отсутствовать вовсе. Официальная
позиция Anthropic — «varying network access» (доступ разный в зависимости
от настроек), однозначной гарантии нет. Если после установки скилла на
claude.ai попытка получить токен Avito ничего не возвращает или падает
с сетевой ошибкой — это ожидаемо, а не поломка: нужен Claude Code.

Если не уверен, что доступно человеку — не гадай, а прямо попробуй вызвать
`POST https://api.avito.ru/token/` и по результату (успех, сетевая ошибка,
таймаут) скажи, работает сеть здесь или нет.

## Шаг 1. Убедиться, что у Avito подключён платный тариф

Ключи API выдаются только при платном тарифе Avito («Расширенный» и выше).
На бесплатном тарифе в настройках нет самого раздела — сначала подключить
тариф в кабинете Avito, иначе шаг 2 не пройти.

## Шаг 2. Получить `client_id` и `client_secret`

1. Кабинет Avito → **Настройки → Avito API**.
2. **Регистрация приложения** → создать приложение.
3. Скопировать `client_id` и `client_secret`.

`client_secret` — это пароль от API. Никогда не пересылать его в переписке,
не вставлять в код, который может попасть в публичный репозиторий или чат.

## Шаг 3. Передать ключи скиллу

Два варианта, в порядке предпочтения:

**Переменные окружения** (не остаются в файлах):
```bash
export AVITO_CLIENT_ID=...
export AVITO_CLIENT_SECRET=...
```

**Файл `.env`**, если используются скрипты из `avito/scripts/` этого
репозитория — он читает ключи из `avito/scripts/.env` и никогда не
коммитится (см. `.gitignore`). Если скилл установлен отдельно от
репозитория, тот же принцип: ключи — только в файле, который не уйдёт
никуда наружу, и никогда — в тексте сообщения человеку.

## Шаг 4. Сеть (только облачный Claude Code)

Если сессия крутится в облачном контейнере (claude.ai/code, не локальный
CLI) — по умолчанию исходящий доступ к `api.avito.ru` закрыт. Нужно:

1. Облачная иконка над строкой сообщения → выбор окружения.
2. Навести на нужное окружение → шестерёнка.
3. **Network access** → **Custom** → добавить `api.avito.ru`.
4. Отметить «Also include default list of common package managers» —
   иначе сломается доступ к GitHub/npm.
5. Сохранить и начать новую сессию — старая сессия настройку не подхватит.

## Шаг 5. Проверить

Запросить токен и профиль кабинета:

```
POST https://api.avito.ru/token/   (grant_type=client_credentials)
GET  https://api.avito.ru/core/v1/accounts/self
```

Если вернулось имя и id кабинета — всё подключено, можно переходить
к сценариям из `SKILL.md`. Если ошибка — по тексту ошибки понятно, что
не так (неверные ключи, тариф не тот, сеть закрыта); не выдумывать данные,
если подключиться не удалось.

## Чего в API нет

Метода «создать объявление» не существует — публикация только через
Автозагрузку (детали в `references/api-methodology.md`). Это не ограничение
настройки, а ограничение самого API Avito.
