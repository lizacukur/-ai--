# Первая настройка: где работает, ключи API, тариф

Читай этот файл, если человек только что установил скилл, ключей Avito нет,
либо он спрашивает «как подключить», «где взять ключи», «почему не видно моих
объявлений».

## Сначала пойми, что человеку вообще нужно

Три этапа скилла требуют разного доступа. Не отправляй человека настраивать
то, что ему не понадобится.

| Что человек хочет | Нужен API | Нужен платный тариф Avito | Где работает |
|---|---|---|---|
| Написать текст объявления, промпты на картинки | нет | нет | где угодно |
| Разобрать статистику кабинета | да, либо цифры руками | нет | Claude Code, Cowork, claude.ai |
| Опубликовать объявление | да | **да, с Автозагрузкой** | **только Claude Code** |

**Если человеку нужен только текст — не заводи разговор про ключи вообще.**
Этап с текстами и макетами не требует ни доступа, ни подписки.

## Где скилл работает надёжно, а где нет

**Claude Code** (CLI, десктоп или облачная версия) — работает всё, включая
публикацию. Единственная среда, где доступен третий этап.

**Claude Cowork** — аналитика и тексты работают, **публикация нет**. Песочница
Cowork ходит в сеть по закрытому списку доменов, который пользователь не может
расширить, и `api.avito.ru` в него не входит. Если человек в Cowork просит
опубликовать объявление — скажи прямо, что для этого нужно перейти в
Claude Code, и объясни почему.

**claude.ai в браузере** — сетевой доступ песочницы зависит от настроек
аккаунта и организации, официально описан как «varying». Гарантий, что запросы
к Avito пройдут, нет. Тексты и макеты работают всегда.

**Браузерное расширение / чтение статистики глазами** — нормальный путь для
первого этапа: человек показывает цифры из кабинета, ты считаешь и разбираешь.
Ключи для этого не нужны.

Если не уверен, что доступно в текущей среде — не гадай, попробуй запросить
токен и по результату скажи, есть здесь сеть или нет.

## Переход из другой среды в Claude Code

Частая ситуация: человек посмотрел статистику через браузер или Cowork, теперь
хочет публиковать. Скажи ему две вещи **до** того, как он пойдёт что-то искать:

1. Публикация делается в Claude Code, в другой среде её нет.
2. Ключи API в Claude Code придётся ввести заново, даже если раньше он их
   где-то вводил. Это другая среда со своим доступом — он ничего не потерял
   и не сделал неправильно.

## Шаг 1. Проверить тариф Avito

Ключи API выдаются только при платном тарифе. Для **публикации** нужен тариф,
в который входит **Автозагрузка** — это отдельное условие поверх наличия ключей.

Проверяется двумя способами:
- в кабинете: `avito.ru/autoload/settings`. Надпись «Автозагрузка недоступна»
  и кнопка выбора подписки означают, что публиковать через фид нельзя;
- через API: `POST /autoload/v2/profile` вернёт 403 с текстом
  «Создание/обновление профиля недоступно».

Важно: **чтение** настроек может работать и показывать `autoload_enabled: true`
при заблокированной записи. Ориентируйся на запись, а не на чтение.

Если Автозагрузки нет — первый и второй этап всё равно доступны. Объявление
публикуется руками через кабинет: текст и картинки уже готовы, это несколько
минут.

## Шаг 2. Получить ключи

1. Кабинет Avito → **Настройки → Avito API**. Раздела нет — значит тариф не тот.
2. **Регистрация приложения** → создать → скопировать `client_id` и
   `client_secret`.

`client_secret` — пароль от API. Никогда не пересылать в переписке, не
вставлять в код, который может попасть в публичный репозиторий, и не
показывать в ответах человеку.

## Шаг 3. Передать ключи скиллу

Переменные окружения (предпочтительно, не остаются в файлах):

```bash
export AVITO_CLIENT_ID=...
export AVITO_CLIENT_SECRET=...
```

Либо файл `.env` рядом со скриптами — он не должен попадать в репозиторий.

## Шаг 4. Сеть (только облачный Claude Code)

Если сессия крутится в облачном контейнере (claude.ai/code), по умолчанию
исходящий доступ к `api.avito.ru` закрыт:

1. Облачная иконка над строкой сообщения → выбор окружения.
2. Шестерёнка у нужного окружения.
3. **Network access** → **Custom** → добавить `api.avito.ru`.
4. Отметить «Also include default list of common package managers» —
   иначе сломается доступ к GitHub и менеджерам пакетов.
5. Сохранить и **начать новую сессию**: старая настройку не подхватит.

## Шаг 5. Проверить

```
POST https://api.avito.ru/token/   (grant_type=client_credentials)
GET  https://api.avito.ru/core/v1/accounts/self
```

Вернулось имя и id кабинета — подключено. Ошибка — назови причину словами
(неверные ключи, тариф не тот, сеть закрыта) и не выдумывай данные.
