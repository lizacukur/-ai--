# Лидогенератор: поиск клиентов для сайтов и ИИ-внедрений

Программа сама:

1. **Находит компании** в 2ГИС и Яндекс Картах по нише и городу.
2. **Проверяет их сайт**: есть ли он вообще, открывается ли с телефона, есть ли HTTPS, онлайн-запись, чат, Яндекс Метрика, когда сайт последний раз обновляли, заполнено ли SEO.
3. **Ищет ЛПР**: директора или ИП по данным ЕГРЮЛ через DaData. Если на сайте указан ИНН, совпадение точное, иначе программа ищет по названию и городу.
4. **Решает, что предложить**: сайт под SEO и Директ, ИИ-помощника по сервису или лидогенерацию для B2B. Ставит каждой компании оценку 0–100.
5. **Пишет первое сообщение**: короткое, без цены, с одним мягким вопросом про консультацию. По шаблону с чередованием формулировок или персонально через нейросеть Claude.
6. **Отдаёт два файла**:
   - `leads_….xlsx` — таблица для работы и учёта;
   - `leads_….html` — **панель отправки**. Открывается в браузере. Кнопка **WhatsApp** открывает чат с уже вставленным текстом, кнопка **Telegram** копирует текст и открывает чат. Там же можно ставить статусы «Написали / Ответили / Созвон / Отказ».

Компании, которые попали в прошлые запуски, программа больше не выдаёт, поэтому одному клиенту не придёт два письма.

---

## Почему отправка не полностью автоматическая

- WhatsApp и Telegram **блокируют номер** за массовые сообщения незнакомым людям. Обычно это происходит уже после нескольких десятков сообщений.
- Закон «О рекламе» (ст. 18, 38-ФЗ) запрещает рассылать рекламу без согласия получателя. Личное сообщение, которое вы отправили вручную и которое касается конкретно его бизнеса, — это переписка, а не рассылка.

Поэтому программа делает всё, кроме последнего клика. Одно сообщение отправляется за 5–10 секунд.

**Советы по отправке:** пишите 20–30 сообщений в день с одного аккаунта, не больше. Перед отправкой прочитайте текст и поправьте, если нужно. Тому, кто попросил больше не писать, не пишите.

## Где взять ключи (пошагово)

Ключ — это длинный «пароль», по которому сервис узнаёт вашу программу. Все ключи вписываются в один файл `.env` (как его создать, описано ниже).

Для старта хватит **одного ключа поиска** (2ГИС или Яндекс). Остальные ключи добавляют возможности, но программа работает и без них.

### 1. 2ГИС — поиск компаний (рекомендую начать с него)

У 2ГИС больше всего данных: телефоны, сайты, WhatsApp и Telegram компаний, рейтинг, число отзывов.

1. Откройте **https://platform.2gis.ru** и нажмите «Войти» / «Зарегистрироваться». Подойдёт вход через почту.
2. В личном кабинете найдите раздел **«Ключи API»** или **«API keys»**.
3. Создайте ключ, в списке сервисов отметьте **Places API** (это поиск организаций).
4. Сначала обычно выдают **демо-ключ** с ограниченным числом запросов, его хватит на пробу. Для постоянной работы нужен платный тариф. Цену уточните у менеджера 2ГИС через форму на сайте, она зависит от объёма.
5. Скопируйте ключ (вида `a1b2c3d4-....`) и вставьте в `.env` после `DGIS_API_KEY=`.

### 2. Яндекс — API Поиска по организациям

1. Откройте **https://developer.tech.yandex.ru** и войдите через Яндекс ID.
2. Нажмите **«Подключить API»** и выберите **«API Поиска по организациям»**.
3. Заполните короткую анкету: название проекта, сайт (можно ссылку на портфолио).
4. Скопируйте ключ и вставьте в `.env` после `YANDEX_MAPS_API_KEY=`.

⚠️ Бесплатный тариф Яндекса ограничен по числу запросов, и его условия разрешают показывать результаты только на карте Яндекса, а не сохранять их в таблицу. Для такой программы по правилам нужна **коммерческая лицензия**. Поэтому начните с 2ГИС, а Яндекс подключайте, когда будете готовы платить.

### 3. DaData — ЛПР (директор, ИНН)

1. Откройте **https://dadata.ru** и нажмите «Регистрация».
2. Подтвердите почту и войдите в **личный кабинет**.
3. Откройте **«Профиль» → «API-ключ»** (https://dadata.ru/profile/#info).
4. Скопируйте **API-ключ** (секретный ключ не нужен) и вставьте после `DADATA_API_KEY=`.

Бесплатного лимита (порядка 10 000 запросов в день) с запасом хватит на старт.

### 4. Claude — персональные сообщения (необязательно)

Без этого ключа сообщения собираются по готовому шаблону, и он уже нормально продаёт. С ключом нейросеть пишет под каждую компанию свой текст.

1. Откройте **https://platform.claude.com** и зарегистрируйтесь.
2. В разделе **Billing** пополните баланс. Сотня сообщений обходится примерно в 1–3 $.
   Учтите: российские карты там не принимают, нужна зарубежная.
3. В разделе **API Keys** нажмите **Create Key** и скопируйте ключ (начинается с `sk-ant-`).
4. Вставьте его после `ANTHROPIC_API_KEY=`.

## Установка и запуск (один раз)

1. Установите **Python 3.11 или новее**: https://www.python.org/downloads/. На Windows при установке поставьте галочку **«Add Python to PATH»**.
2. Скачайте эту папку `leadgen` к себе на компьютер.
3. Сделайте копию файла `.env.example`, назовите её `.env` и впишите ключи.
4. Откройте терминал в папке `leadgen`. На Windows: в адресной строке папки наберите `cmd` и нажмите Enter. Затем выполните:

```
pip install -r requirements.txt
```

### Каждый запуск

Найти стоматологии и автосервисы в Казани:

```
python -m leadgen search --cities Казань --niches dental auto_service
```

Все ниши во всех городах из `config.yaml` (это долго и тратит лимиты):

```
python -m leadgen search
```

Для пробы возьмите 10 компаний на запрос:

```
python -m leadgen search --cities Москва --niches beauty_clinic --limit 10
```

Проверить свой список компаний (CSV с колонками `name, city, niche, website, phone`):

```
python -m leadgen csv мой_список.csv --niche dental
```

Список кодов ниш: `python -m leadgen niches`

Результаты сохраняются в папку `output/`. Откройте `.html` в браузере, это и есть рабочая панель.

## Настройка под себя: файл `config.yaml`

- `sender` — ваше имя, название студии и ссылка на портфолио, они попадают в подпись.
- `offers` — описания и цены (сайт от 80 000 ₽, ИИ от 20 000 ₽, лидогенерация).
- `cities` — города.
- `niches` — ниши: какие запросы искать, насколько ниша зависит от повторных визитов (`ltv`), что предлагать и на какую боль давить.

## Как программа ищет ЛПР

1. **ИНН с сайта** — точное совпадение. Если сайта нет в выдаче карт (так бывает на демо-ключе 2ГИС), программа пробует подобрать его по названию (`dinastiya-spb.ru`, `takihodi.ru`) и принимает сайт, только если на нём та же улица, что в карточке.
2. **ИНН из `data/inn.csv`** — те, что вы нашли сами (например, на rusprofile.ru или в разделе «Правовая информация» на сайте клиники). Формат:
   ```
   brand,city,inn
   Skin Buro,Санкт-Петербург,7840080124
   ```
   `brand` — название из 2ГИС до запятой.
3. **Подбор по ЕГРЮЛ** — ищем юрлицо с похожим названием в этом регионе и берём то, у которого совпадает адрес или вид деятельности (ОКВЭД из `config.yaml`). Колонка «Точность ЛПР» показывает, как найдено: «точно», «вероятно (название и адрес)» или «предположительно». Последние проверьте перед обращением по имени.
4. Если сайта нет в выдаче карт, его можно вписать в `data/sites.csv` (колонки `brand,city,website`). Программа зайдёт на сайт и соберёт телефоны, WhatsApp, Telegram, MAX и ИНН.
5. Директор, найденный у одного филиала сети, переносится на другие филиалы того же бренда в городе.

## Какие сообщения пишет программа

Задача первого сообщения: получить ответ, а не продать. Поэтому в нём нет цены. Структура: заход, который показывает, что мы понимаем их бизнес (на ком держатся деньги), затем представление и главная услуга (нейросети в сервисе, чтобы клиенты возвращались), затем продвижение в Яндексе с помощью нейросетей, один вопрос и P.s. со ссылкой.

```
Здравствуйте, Андрей Владимирович!

Вижу, вы работаете в сфере автосервиса, а здесь деньги делают постоянные клиенты, которые приезжают на ТО, сезонную смену шин и повторный ремонт.

Меня зовут Елизавета, я внедряю нейросети в сервис, чтобы клиенты возвращались к вам снова. Например, напоминания о ТО и смене шин, запись в пару кликов и сообщение, когда машина готова.

Также мы продвигаем компании в Яндексе с помощью нейропомощников, чтобы новые клиенты находили вас.

Есть смысл обсудить это на короткой консультации?

P.s.: первичная консультация полностью бесплатна и не займёт много времени. Мой контакт: https://t.me/lizaai_consult
```

- Приветствие, заход, формулировки услуг и вопрос чередуются от письма к письму, чтобы сообщения не выглядели рассылкой.
- Каждое сообщение проверяется: ровно один вопрос, дословный P.s., нет «—», «Привет», цены и «бесплатно» вне P.s. Если нейросеть нарушила правило, программа подставляет шаблон.
- Формулировки для каждой ниши лежат в `config.yaml`: `sphere` (сфера), `place` и `repeat` (на ком держатся деньги), `service` (что автоматизируем). P.s. в `messages.ps`, имя для представления в `messages.intro_name`.
- Цифры и статистику в сообщения не вставляем, пока нет источника, на который можно сослаться.

## Как программа выбирает предложение

- **Сайт** — если сайта нет, он не открывается, не работает на телефоне, давно не обновлялся или не настроен под SEO.
- **ИИ-помощник** — если сайт в порядке, а ниша живёт за счёт повторных визитов (клиники, салоны, автосервисы, фитнес, ветклиники). Оценка растёт, когда много отзывов (большая база клиентов), рейтинг ниже 4.6 (проседает сервис), несколько филиалов, нет онлайн-записи или чата.
- **Лидогенерация** — для B2B-ниш.

## Ограничения

- Телефон из 2ГИС или с сайта — чаще всего телефон ресепшена, а не директора. Имя директора из ЕГРЮЛ помогает: обращайтесь по имени-отчеству и просите передать сообщение. Это заметно повышает шанс дойти до ЛПР.
- Ссылку на MAX программа берёт только с сайта компании (`max.ru/…`). Открыть чат в MAX по номеру телефона программа пока не умеет.
- Кнопка Telegram по номеру сработает, только если человек разрешил искать себя по номеру.
- Некоторые сайты закрыты от программ. В таблице у них будет пометка «Не удалось проверить сайт автоматически», такие сайты посмотрите вручную.
