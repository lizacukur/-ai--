# Установка: Claude + Avito

Пошаговая инструкция. Если что-то из этого уже настроено — пропусти шаг.

## 0. Что понадобится

- Аккаунт Avito с подключённым **платным тарифом** («Расширенный» или выше).
  Без него в настройках нет раздела Avito API — бесплатные тарифы доступа
  к API не дают.
- **Claude Code** — в терминале, десктоп-приложении или в облаке на
  claude.ai/code. Это единственный способ, где сетевой доступ к Avito API
  гарантирован.
- `git` и `python3` — для установочного скрипта.

Это скилл под Claude, не под ChatGPT — там свой формат плагинов, и никто
его под этот скилл ещё не собрал.

Скилл можно установить и на claude.ai в браузере (обычный чат с загрузкой
скиллов файлом), но там доступ песочницы в интернет зависит от настроек
аккаунта/организации и не гарантирован — Avito может быть недоступен без
дополнительных настроек, до которых у обычного пользователя доступа нет.
Если нужна предсказуемая работа — ставь через Claude Code, это описано ниже.

Если у тебя только файлы `avito-strategist.zip`/`avito-api.zip`, а не весь
репозиторий — можно пропустить установку через `setup.sh` и просто
распаковать оба архива в `~/.claude/skills/`. Дальше все шаги про ключи
(1, 2, 4, 5) точно такие же. Тот же порядок действий, что и ниже, вшит и
в сам скилл — файл `references/getting-started.md` внутри
`avito-strategist.zip` — так что Claude сможет провести по шагам сам,
если просто спросить «как подключить API».

## 1. Получить ключи Avito API

1. Зайти в кабинет Avito → **Настройки → Avito API**.
   Если раздела нет — значит тариф не тот, сначала подключить платный.
2. **Регистрация приложения** → создать приложение → скопировать
   `client_id` и `client_secret`.
3. `client_secret` — это пароль от API. Не пересылать в чатах и почте,
   хранить только в файле `.env` (см. ниже).

## 2. Сетевой доступ (только для Claude Code в облаке)

Если работаешь с Claude Code локально на своём компьютере — пропусти этот
шаг, локальная сеть ничем не ограничена.

Если работаешь в облачной версии (claude.ai/code, сессия крутится в
изолированном контейнере) — по умолчанию исходящий доступ к `api.avito.ru`
закрыт, и без этого шага скилл не сможет достучаться до Avito.

1. На claude.ai/code — облачная иконка над строкой сообщения (выбор
   окружения).
2. Навести на нужное окружение → иконка шестерёнки.
3. В диалоге настроек окружения: **Network access** → выбрать **Custom**.
4. Добавить в список `api.avito.ru`.
5. Отметить галочку «Also include default list of common package managers»
   — иначе сломается доступ к GitHub/npm и прочим обычным менеджерам
   пакетов, которые нужны для установки скилла.
6. Сохранить.

Изменения применяются только к **новым** сессиям — уже открытую сессию
нужно закрыть и начать заново.

## 3. Установить скиллы

Из корня этого репозитория:

```bash
bash avito/scripts/setup.sh
```

Скрипт:
- проверит, что `git` и `python3` есть;
- поставит `avito-api` (чужой скилл, доступ к самому API, 238 методов) —
  клонирует [MissiaL/avito-api](https://github.com/MissiaL/avito-api) в
  `~/.claude/skills/avito-api`;
- скопирует `avito-strategist` (этот скилл — стратегия, диагностика, тексты)
  из `.claude/skills/avito-strategist` этого репозитория в
  `~/.claude/skills/avito-strategist`;
- создаст пустой файл `avito/scripts/.env` для ключей, если его ещё нет.

Запускать можно сколько угодно раз — обновляет, а не ломает. После правок
в `.claude/skills/avito-strategist/` этого репозитория запусти скрипт
заново, чтобы обновить установленную копию.

## 4. Вписать ключи

Открыть `avito/scripts/.env` и вписать:

```
AVITO_CLIENT_ID=...
AVITO_CLIENT_SECRET=...
```

Файл в `.gitignore` — в репозиторий не попадёт и никуда не отправится сам.

## 5. Проверить связь

```bash
bash avito/scripts/setup.sh
```

Второй запуск подтянет ключи из `.env`, получит токен и покажет название
кабинета — если видно имя и id, всё подключено.

Если вместо этого ошибка — проверить:
- ключи вписаны без лишних пробелов и кавычек;
- на Avito подключён платный тариф;
- (для облачной версии) шаг 2 про сетевой доступ выполнен и сессия
  перезапущена.

## 6. Перезапустить Claude

Claude Code подхватывает новые скиллы при старте новой сессии — закрыть
текущую и открыть заново (или, если работаешь в claude.ai, обновить
страницу).

## 7. Проверить, что всё работает

Написать Claude обычными словами:

> разбери мой авито

Если скилл видит кабинет — в ответе будут реальные цифры: число объявлений,
просмотры, контакты, расход на продвижение. Если ключи не настроены или
сеть закрыта — Claude скажет об этом прямо, а не придумает цифры.

## Если ключей и API нет

Можно работать и без доступа к API — через ручной ввод цифр из кабинета
в `avito/scripts/my_stats.csv` и запуск:

```bash
python3 avito/scripts/manual_stats.py
```

Разбор будет тем же самым, просто без автоматической выгрузки.
