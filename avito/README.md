# Claude + Avito

Связка, которая даёт Claude доступ к твоему кабинету Avito: разобрать статистику,
найти слабые объявления, написать новые под запрос, ответить в чате, решить,
куда вложить бюджет.

## Установка

```bash
bash avito/setup.sh
```

Скрипт ставит два скилла в `~/.claude/skills`, создаёт файл для ключей
и проверяет связь с Avito. Запускать можно сколько угодно раз — он обновляет,
а не ломает.

Потом впиши ключи в `avito/.env`:

```
AVITO_CLIENT_ID=...
AVITO_CLIENT_SECRET=...
```

Где взять: кабинет Avito → **Настройки → Avito API → регистрация приложения**.
Нужен платный тариф — без него раздела нет.

Запусти `bash avito/setup.sh` ещё раз: он проверит ключи и скажет, чей это кабинет.
Перезапусти Claude Code — и всё.

## Как пользоваться

Обычными словами, без команд:

- «разбери мой авито»
- «почему по объявлению про ChatGPT не пишут»
- «напиши новое объявление под запрос "нейросети для маркетологов"»
- «куда вложить 3000 рублей на продвижение»
- «что ответить в чате»
- «покажи, сколько я потратила за месяц и сколько это принесло»

## Из чего собрано

| Скилл | Что делает | Чей |
|---|---|---|
| `avito-api` | доступ к Avito Business API: 238 методов, полный официальный спек | [MissiaL/avito-api](https://github.com/MissiaL/avito-api), MIT |
| `avito-strategist` | стратегия, диагностика, тексты объявлений, скрипты переписки | наш, лежит в `.claude/skills/` |

Первый — руки, второй — голова. Правки вносим во второй: он в этом репозитории,
после правок прогнать `bash avito/setup.sh`, чтобы обновить установленную копию.

## Что можно делать через API

**Читать — всё:**
объявления, статистику просмотров и контактов, расходы на продвижение,
звонки, отзывы и рейтинг, баланс, переписку в мессенджере.

**Менять — многое:**
цену объявления, услуги продвижения, ответы на отзывы, сообщения в чатах.

**Публиковать новые объявления — только через Автозагрузку.**
Метода «создать объявление» в API нет. Публикация идёт файлом-фидом, который
Avito забирает по ссылке. Пока автозагрузка не настроена, новое объявление
размещается руками — текст Claude напишет, опубликовать 10 минут.

## Если API недоступен

Остаются два скрипта, они работают без ключей:

```bash
python3 avito/manual_stats.py   # цифры из кабинета, занесённые в avito/my_stats.csv
python3 avito/avito_stats.py    # выгрузка через API, если ключи есть
```

Разбор одинаковый — считает общий модуль `report.py`.

## Стратегия

`avito/strategiya.md` — разбор площадки, два сегмента, банк заголовков,
шесть готовых текстов, план на четыре недели.

## Про ключи

`client_secret` — это пароль. Не пересылать в переписке и мессенджерах.
Место одно: `avito/.env`, он в `.gitignore`. Если ключ куда-то ушёл —
перевыпустить в кабинете, старый сразу перестанет работать.
