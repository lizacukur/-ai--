# Claude + Avito

Связка, которая даёт Claude доступ к кабинету продавца на Avito: разобрать
статистику, найти слабые объявления, написать новые под запрос, ответить
в чате, решить, куда вложить бюджет на продвижение.

Работает для любой ниши — товаров и услуг. Готового примера под конкретный
бизнес нет, скилл сам разбирается в твоей нише по объявлениям в кабинете
и по разговору с тобой. Если хочется посмотреть, как это выглядит на живом
примере — в `examples/neuro-education/` лежит разбор одной ниши (обучение
работе с нейросетями) целиком: сегменты аудитории, готовые тексты, план
на месяц. Это иллюстрация метода, не шаблон — своя ниша переносится не
копированием текстов, а тем же способом рассуждения.

## Важно: что это и для чего

Это **скилл для Claude** — не отдельное приложение и не плагин для ChatGPT.
Чтобы получить то же самое в ChatGPT, кто-то должен собрать под него
отдельную интеграцию — формат скиллов Claude там не работает.

Внутри Claude — тоже не всё равно, где ставить:

- **Claude Code** (CLI, десктоп или облачная версия на claude.ai/code) —
  надёжно работает, у сессии есть обычный доступ в интернет для запросов
  к Avito API.
- **claude.ai в браузере** (обычный чат с загруженными скиллами) — скилл
  выполняется в песочнице, и её доступ к интернету зависит от настроек
  аккаунта/организации: может быть полным, ограниченным или отсутствовать.
  Официально это называется «varying network access» — однозначной
  гарантии, что запросы к `api.avito.ru` пройдут, нет. Если после установки
  запросы не проходят — это ожидаемо, нужен Claude Code.

Если пользуешься только ChatGPT — этот скилл тебе не подойдёт.

Подробный пошаговый гайд по установке — в [`INSTALL.md`](./INSTALL.md). Та же
инструкция зашита и в сам скилл — файл
`.claude/skills/avito-strategist/references/getting-started.md` — так что
если кто-то поставил только скилл, без остального репозитория, Claude сам
проведёт его через получение ключей и подключение, стоит только спросить
«как подключить» или «где взять ключи api».

## Быстрый старт

```bash
bash avito/scripts/setup.sh
```

Скрипт ставит два скилла в `~/.claude/skills`, создаёт файл для ключей
и проверяет связь с Avito. Запускать можно сколько угодно раз — он обновляет,
а не ломает.

Потом впиши ключи в `avito/scripts/.env`:

```
AVITO_CLIENT_ID=...
AVITO_CLIENT_SECRET=...
```

Где взять: кабинет Avito → **Настройки → Avito API → регистрация приложения**.
Нужен платный тариф на Avito — без него этого раздела в кабинете нет.

Запусти `bash avito/scripts/setup.sh` ещё раз: он проверит ключи и скажет,
чей это кабинет. Перезапусти Claude (или начни новую сессию Claude Code) —
и всё готово.

Если работаешь в Claude Code в облаке (claude.ai/code) — доступ к
`api.avito.ru` нужно явно разрешить в настройках сетевого доступа окружения.
Это отдельный шаг, он тоже описан в `INSTALL.md`.

## Как пользоваться

Обычными словами, без команд:

- «разбери мой авито»
- «почему по этому объявлению не пишут»
- «напиши новое объявление под запрос "..."»
- «куда вложить 3000 рублей на продвижение»
- «что ответить в чате»
- «покажи, сколько я потратил(а) за месяц и сколько это принесло»

## Из чего собрано

| Скилл | Что делает | Чей |
|---|---|---|
| `avito-api` | доступ к Avito Business API: 238 методов, полный официальный спек | [MissiaL/avito-api](https://github.com/MissiaL/avito-api), MIT |
| `avito-strategist` | стратегия, диагностика, тексты объявлений, скрипты переписки | наш, лежит в `.claude/skills/` этого репозитория |

Первый — руки, второй — голова. Правки вносим во второй: он в этом
репозитории, после правок прогнать `bash avito/scripts/setup.sh`, чтобы
обновить установленную копию.

## Что можно делать через API

**Читать — всё:**
объявления, статистику просмотров и контактов, расходы на продвижение,
звонки, отзывы и рейтинг, баланс, переписку в мессенджере.

**Менять — многое:**
цену объявления, услуги продвижения, ответы на отзывы, сообщения в чатах.

**Публиковать новые объявления — только через Автозагрузку.**
Метода «создать объявление» в API нет. Публикация идёт файлом-фидом, который
Avito забирает по ссылке. Пока автозагрузка не настроена, новое объявление
размещается руками — текст Claude напишет, опубликовать несколько минут.

## Если API недоступен

Остаются два скрипта, они работают без ключей:

```bash
python3 avito/scripts/manual_stats.py   # цифры из кабинета, занесённые в avito/scripts/my_stats.csv
python3 avito/scripts/avito_stats.py    # выгрузка через API, если ключи есть
```

Разбор одинаковый — считает общий модуль `avito/scripts/report.py`.

Есть и отдельный однофайловый скрипт без установки скилла и без зависимостей
кроме стандартной библиотеки — `avito/scripts/avito_report.py`, включая
`--demo` режим на тестовых данных, чтобы посмотреть формат отчёта без ключей.

## Пример под нишу

`avito/examples/neuro-education/` — заполненный пример: разбор площадки,
сегменты аудитории, банк заголовков, шесть готовых текстов объявлений,
план на четыре недели. Смотри `README.md` внутри папки — там же объяснено,
как адаптировать метод под свою нишу, а не копировать тексты.

## Про ключи

`client_secret` — это пароль. Не пересылать в переписке и мессенджерах.
Место одно: `avito/scripts/.env`, он в `.gitignore` и в репозиторий не
попадает. Если ключ куда-то ушёл — перевыпустить в кабинете Avito,
старый сразу перестанет работать.
