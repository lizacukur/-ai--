# Статистика Avito → анализ

Два пути к одному и тому же разбору: через официальное API или руками.
Считает и выдаёт вердикты в обоих случаях один модуль — `report.py`.

| Скрипт | Когда нужен |
|---|---|
| `manual_stats.py` | всегда работает: цифры берутся из кабинета и заносятся в таблицу |
| `avito_stats.py` | если в кабинете есть раздел API (нужен платный тариф) |

---

## Про безопасность ключа

`client_secret` — это пароль к твоему кабинету для программ. Правила простые:

- Не отправлять его в переписке, чате и мессенджерах. Если уже отправила —
  зайти в кабинет и **перевыпустить ключ**, старый перестанет работать.
- Хранить только в файле `avito/.env` — он в `.gitignore` и в репозиторий не попадёт.
- Ключ отзывается и создаётся заново в кабинете в любой момент, без последствий
  для объявлений.

## Путь 1. Руками — работает всегда

Ничего настраивать не нужно.

### Где взять цифры

Кабинет Avito → раздел **«Аналитика»**. Там по каждому объявлению видны
просмотры, контакты и избранное за период — неделя, месяц, всё время.
Просмотры и контакты видны и в карточке самого объявления.

### Что сделать

1. Открыть `avito/my_stats.csv` — в Excel, Google Таблицах или обычном блокноте.
2. Вписать свои объявления и цифры. Колонки:

   | Колонка | Обязательна | Что вписать |
   |---|---|---|
   | `объявление` | да | заголовок, как он стоит на Avito |
   | `просмотры` | да | за выбранный период |
   | `контакты` | да | сколько раз написали или позвонили |
   | `избранное` | нет | сколько добавили в избранное |
   | `расход` | нет | сколько ушло на продвижение этого объявления, ₽ |

   Пустые `избранное` и `расход` — нормально, просто не будет стоимости обращения.

3. Запустить:

```bash
python3 avito/manual_stats.py
```

Числа можно писать как угодно — `1 240`, `1240`, `1 240,0` разберутся одинаково.
Разделитель в файле — точка с запятой или запятая, скрипт определит сам.

## Путь 2. Через API — если есть платный тариф

### Где в кабинете

**Настройки → «Для профессионалов» → API.** Раздела не видно, если на аккаунте
нет платного тарифа — тогда остаётся путь 1, он даёт тот же разбор.

### Настройка

Создать файл `avito/.env`:

```
AVITO_CLIENT_ID=сюда_client_id
AVITO_CLIENT_SECRET=сюда_client_secret
```

### Запуск

```bash
python3 avito/avito_stats.py            # за последние 60 дней
python3 avito/avito_stats.py --days 180 # за полгода
```

Ставить ничего не нужно — только Python 3.

## Что получится

В папке `avito/out/`:

| Файл | Что внутри |
|---|---|
| `report_ГГГГ-ММ-ДД.md` | отчёт: итоги, таблица по объявлениям, вердикт по каждому |
| `avito_stats_ГГГГ-ММ-ДД.csv` | те же цифры таблицей — открывается в Excel |
| `avito_raw_ГГГГ-ММ-ДД.json` | сырой ответ Avito (только у пути через API) |

Отчёт можно прислать в чат — по нему разбирается, какие объявления
масштабировать, какие переписывать, а какие выключить.

## Что считается

- **CR (просмотр → контакт)** — сколько процентов увидевших написали или позвонили.
  Ориентир для обучения и услуг: 3–8%. Ниже 2% — проблема в объявлении,
  а не в бюджете.
- **Стоимость обращения** — расход ÷ контакты. Считается, если заполнена колонка `расход`.
- **Вердикт** — где узкое место: не хватает показов, не работает оффер,
  или объявление уже победитель и его надо масштабировать.

## Ограничения

- Через API Avito отдаёт статистику максимум за 270 дней и порциями
  по 200 объявлений — скрипт сам разбивает запрос на части.
- Расходы на продвижение API в этом виде не отдаёт: сумму надо взять
  в кабинете и вписать руками в колонку `расход`.
- Путь через API написан по документации, но не прогнан на живом кабинете.
  Если на первом запуске что-то отвалится — пришли текст ошибки, поправлю.
