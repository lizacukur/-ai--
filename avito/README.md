# Статистика Avito → анализ

Скрипт забирает из твоего кабинета Avito все объявления и их статистику
(просмотры, контакты, избранное), считает конверсию по каждому объявлению
и собирает отчёт.

Нужен один раз настроенный ключ доступа. Логин и пароль от Avito нигде не вводятся
и никому не передаются.

## 1. Получить ключ доступа

1. Зайти на avito.ru под своим аккаунтом.
2. Профиль → **Настройки** → раздел **API** (может называться «Для разработчиков»).
3. Создать приложение → скопировать **client_id** и **client_secret**.

Ключ даёт доступ только на чтение того, что ты сама разрешишь, и отзывается
в кабинете в любой момент.

## 2. Положить ключ в файл

Создать файл `avito/.env` (он в `.gitignore`, в репозиторий не попадёт):

```
AVITO_CLIENT_ID=сюда_client_id
AVITO_CLIENT_SECRET=сюда_client_secret
```

## 3. Запустить

```bash
python3 avito/avito_stats.py            # за последние 60 дней
python3 avito/avito_stats.py --days 180 # за полгода
```

Ничего доустанавливать не нужно — только Python 3.

## 4. Что получится

В папке `avito/out/` появятся три файла:

| Файл | Что внутри |
|---|---|
| `report_ГГГГ-ММ-ДД.md` | готовый отчёт: итоги, таблица по объявлениям, вердикт по каждому |
| `avito_stats_ГГГГ-ММ-ДД.csv` | те же цифры таблицей — открывается в Excel и Google Таблицах |
| `avito_raw_ГГГГ-ММ-ДД.json` | сырой ответ Avito — на случай, если нужно копнуть глубже |

Отчёт и raw-файл можно прислать в чат — по ним разбирается, какие объявления
масштабировать, какие переписывать, а какие выключить.

## Что скрипт считает

- **CR (просмотр → контакт)** — сколько процентов увидевших объявление написали или позвонили.
  Ориентир для обучения и услуг: 3–8%. Ниже 2% — проблема в самом объявлении, а не в бюджете.
- **Вердикт по объявлению** — где именно узкое место: не хватает показов, не работает оффер
  или объявление уже победитель и его надо масштабировать.

## Ограничения

- Avito отдаёт статистику максимум за 270 дней и порциями по 200 объявлений —
  скрипт сам разбивает запрос на части.
- Расходы на платное продвижение API в этом объёме не отдаёт: сумму, потраченную
  на продвижение за период, нужно взять в кабинете вручную, чтобы посчитать
  стоимость одного обращения.
- Скрипт написан по документации Avito, но не был прогнан на живом кабинете
  (из среды разработки api.avito.ru недоступен). Если на первом запуске что-то
  отвалится — пришли текст ошибки, поправлю.
